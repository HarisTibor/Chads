# Szakmai Ismeretek Összefoglaló

## 1. Programozás és Szoftverfejlesztés

### Python Programozás
A Python egy magas szintű, interpretált nyelv, amely a könnyű olvashatóságra és a hatékonyságra fókuszál.
* **Alapok:** Adattípusok (string, int, list, dict), vezérlési szerkezetek (if, for, while).
* **OOP:** Osztályok, objektumok, egységbezárás és öröklődés.
* **Környezet:** Modulok kezelése (`pip`) és virtuális környezetek (`venv`).

### Agilis Módszertanok
A modern szoftverfejlesztés során alkalmazott keretrendszerek a hatékonyság növelésére.

| Módszertan | Leírás és Kulcsfogalmak |
| :--- | :--- |
| **Scrum** | Iteratív fejlesztés, Sprint alapú munkavégzés, Daily Stand-up. |
| **Kanban** | Folyamatos munkafolyamat-vizualizáció, WIP (Work In Progress) limitek. |
| **LSD** | *Lean Software Development*: Pazarlás megszüntetése, gyors szállítás. |
| **XP** | *Extreme Programming*: Teszt-vezérelt fejlesztés (TDD), páros programozás. |

## 2. rendszerüzemeltetés

### Virtualizáció
* **Lényege:** Egy fizikai hardveren több, egymástól független operációs rendszer (VM) futtatása.
* **Hipervizor:** A réteg, ami kezeli a virtuális gépeket (pl. VMware, Hyper-V).

### Konténerizáció
* **Lényege:** Az alkalmazás és annak összes függősége egyetlen egységbe csomagolva.
* **Előnye:** Sokkal kisebb az erőforrásigénye, mint a VM-nek, mert osztozik a gazdagép kernelén (pl. Docker).

## 3. Matematika

### Egyenletek
Az algebrai egyenletek megoldása során a cél az ismeretlen értékének meghatározása mérlegelvvel.

**Általános forma:**
$$ax + b = c$$

**Megoldás lépései:**
1. Zárójelek felbontása (ha van).
2. Összevonás az oldalakon belül.
3. Rendezés (változók az egyik oldalra, számok a másikra).
4. Osztás az ismeretlen együtthatójával.

### Szöveges feladatok
A szöveges feladatok megoldásának kulcsa a "fordítás" a magyar nyelv és a matematika nyelve között.

* **Ismeretlen kijelölése:** Legyen $x$ a keresett mennyiség.
* **Összefüggések:** "Valaminél 5-tel több" $\rightarrow x + 5$; "valaminek a háromszorosa" $\rightarrow 3x$.
* **Ellenőrzés:** Minden esetben visszahelyettesítéssel az eredeti szövegbe!
